# Команды проекта (Terminal Commands Log)

В этом файле фиксируются основные команды, используемые для разработки и управления проектом.

## Управление каталогом

### 1. Импорт товаров из Excel
Команда импортирует товары, бренды и категории из файла `docs/test.xlsx`. Также скачивает изображения и создает SEO-оптимизированные названия для них.

```powershell
venv\Scripts\python.exe manage.py import_products
```
**Описание:**
- Очищает старые данные изображений.
- Читает `docs/test.xlsx`.
- Автоматически создает бренды и дерево категорий (используя MPTT).
- Скачивает изображения по ссылкам из файла и сохраняет их в `media/products/`.
- Генерирует слаги (slug) для URL на основе названий.
