# Aquatavr - Каталог товаров для подводной охоты

Django-приложение для управления каталогом товаров, брендами и категориями с мощным инструментом импорта из Excel.

## Основные возможности

- **Иерархический каталог:** Поддержка категорий любой вложенности (django-mptt).
- **Варианты товаров (SKU):** Учет характеристик (размер, толщина неопрена, длина) для каждого торгового предложения.
- **Оптимизированный импорт:** 
    - Загрузка данных из Excel-файлов.
    - **SEO-именования:** Автоматическое переименование изображений по шаблону `slug-товара-номер.jpg`.
    - **Защита от дублей:** Интеллектуальная проверка изображений по URL (одно фото сохраняется только один раз, даже если оно используется в 10 вариантах товара).
    - **Высокая скорость:** Многопоточная загрузка изображений (ThreadPoolExecutor), что позволяет быстро импортировать тысячи товаров.

## Технологии

- **Backend:** Python 3.x, Django 6.0
- **База данных:** PostgreSQL / SQLite
- **Инструменты:** Pandas (обработка Excel), Requests (загрузка фото), Pillow (обработка изображений).

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/aquatavr.git
   cd aquatavr
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/Mac
   venv\Scripts\activate     # Для Windows
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Выполните миграции:**
   ```bash
   python manage.py migrate
   ```

5. **Запустите сервер:**
   ```bash
   python manage.py runserver
   ```

## Импорт товаров

Для запуска импорта положите файл `test.xlsx` в папку `docs/` и выполните команду:
```bash
python manage.py import_products
```

## Структура проекта

- `catalog/` - Основное приложение каталога (модели, импорт).
- `core/` - Общие компоненты системы.
- `media/` - Хранилище загруженных изображений товаров.
- `docs/` - Документация и файлы для импорта.
